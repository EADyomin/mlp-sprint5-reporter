# Описание проекта
Учебный проект 6 спринта: Инструменты разработки и основы ООП

## Задача проекта
Вы работаете в команде аналитиков и каждую неделю получаете свежие датасеты из разных отделов. Каждый раз кто-то заново пишет код для подсчёта базовых статистик, поиска пропусков, проверки дубликатов — и каждый делает это немного по-своему. Тимлид поставил задачу: создать единый инструмент для первичной диагностики данных — класс DataFrameReporter. Этому будет посвящена первая часть учебного проекта.
Этот класс должен принимать любой датафрейм и выдавать стандартный отчёт — количество строк и столбцов, дубликаты, сводную статистику и информацию о пропусках. Его можно будет написать один раз и переиспользовать для других задач. 
Создать класс — это только половина дела. В реальной работе код живёт не в учебном тренажёре, а в профессиональной IDE. Его нужно хранить в репозитории, версионировать через Git и оформлять так, чтобы коллеги могли легко запустить ваш проект. Этому будет посвящена вторая часть вашего проекта.

## Задания
### Опишите пустой класс с именем DataFrameReporter. 

Создайте экземпляр класса и положите его в переменную reporter. Выведите на экран тип этой переменной с помощью функции type.

### Добавьте в конструктор класса три параметра и сохраните их значения в свойствах для дальнейшего использования:

float_format — формат вывода на экран чисел с плавающей точкой. Будет использоваться другими методами класса для единообразного оформления отчёта. Установите для этого параметра значение по умолчанию '0.05f': так можно будет создавать экземпляр класса, не перечисляя его параметры, если нет необходимости выводить значения с другой точностью.

percent_format — формат вывода на экран процентов. Установите для этого параметра значение по умолчанию '0.02%' — для процентов в типовом отчёте вполне достаточно видеть не более двух цифр в дробной части.

include_all — режим вывода информации о столбцах датафрейма. Так же, как и остальные параметры, будет использоваться в других методах класса. 

Принимает булевое значение: 

False — выводить информацию только о числовых столбцах датафрейма, 

True — выводить информацию обо всех столбцах датафрейма (аналог include='all' в методе describe библиотеки pandas). 

Задайте значением по умолчанию false, чтобы поведение класса было похоже на настройки pandas.

Внутри конструктора сохраните значения переданных параметров в одноимённые свойства объекта, используя self. Эти значения понадобятся потом для управления выводом отчёта о датафрейме.
Не удаляйте и не изменяйте код создания переменной reporter. Нужно лишь правильно описать тело класса и его конструктор.

### Добавьте в класс метод show_report, который принимает следующие параметры:

df — датафрейм pandas, по которому нужно вывести отчёт.

title — строка с заголовком отчёта. Установите для этого параметра значение по умолчанию None, чтобы была возможность выводить заголовок только при необходимости.

Метод должен выполнять действия в таком порядке:
Если параметр title не равен None, вывести его значение — это будет заголовок отчёта. Затем вывести текст с подставленными значениями, рассчитанными по датафрейму df:
> Количество столбцов: 0
> Количество строк: 0
> Количество дубликатов: 0
> Доля дубликатов: 1.62%

Для форматирования чисел удобно использовать встроенную функцию Python format(value, format_spec='', /). В первый аргумент передайте само значение (например, долю дубликатов), во второй — строку формата, сохранённую в свойстве percent_format. Именно в таком виде нужно вывести долю дубликатов в отчёте.

Теперь в описании класса должен быть конструктор (он уже есть в прекоде) и новый метод, который вы напишете сами.

Экземпляр класса с параметрами по умолчанию уже создан в прекоде и сохранён в переменную reporter. Его и будем использовать для проверки.
Вызовите метод show_report, передав в него датафрейм data (он уже загружен из файла в прекоде и сохранён в переменной data).

### Теперь нужно дополнить отчёт сводной статистикой по числовым и категориальным столбцам датафрейма.

Добавьте в метод show_report вызов describe с параметром include='all', если свойство include_all равно True. Если include_all равно False,, то используйте при вызове describe значение параметра include по умолчанию.

Код за пределами класса менять не нужно. Это тесты, которые проверят правильность обновления метода show_report.

### При первом взгляде на датафрейм полезно сразу увидеть, какая часть данных содержит пропуски. Это помогает быстро оценить качество набора данных.

Добавьте в конец метода show_report вывод общего количества пропусков и их доли по всему датафрейму — по всем строкам и столбцам. Долю нужно вывести в формате, который задан в float_format.

Для форматирования доли пропусков снова удобно использовать стандартную функцию Python — format со следующим описанием: format(value, format_spec='', /). В неё, например, можно в первом параметре передать долю пропусков, а во втором — строку форматирования, которую ранее сохранили в свойстве float_format.

Код за пределами класса менять не нужно. Это тесты, которые проверят правильность обновления метода show_report.
